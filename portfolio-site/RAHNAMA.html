راهنمای راه‌اندازی پرتفولیو

با این هشت مرحله، سایت را منتشر می‌کنی و از پنل ادمین همه‌چیز را تغییر می‌دهی. هزینه‌ای ندارد.

  1. ساخت مخزن در گیت‌هاب

    در سایت github.com حساب بساز یا وارد شو. روی New repository بزن و یک نام مثل my-portfolio بده. گزینه‌ی Public را انتخاب کن و مخزن را بساز. عمومی بودن مخزن ساده‌ترین حالت است و ورود به پنل ادمین در آن کمتر مشکل دارد.

  2. بارگذاری فایل‌ها

    فایل portfolio-site.zip را روی کامپیوتر از حالت فشرده دربیاور. در صفحه‌ی مخزن روی uploading an existing file بزن. همه‌ی فایل‌ها و پوشه‌های داخل آن را بکش و رها کن: index.html، content.json، admin، vendor و assets. خود فایل فشرده را بارگذاری نکن. بعد روی Commit changes بزن.

  3. انتشار در نتلیفای

    در netlify.com با همان حساب گیت‌هاب وارد شو. این گزینه‌ها را به ترتیب بزن: Add new site، بعد Import an existing project، بعد GitHub و مخزن خودت. فیلد Build command را خالی بگذار. در فیلد Publish directory یک نقطه بنویس یا آن را خالی بگذار. بعد روی Deploy بزن. چند ثانیه بعد آدرسی شبیه my-portfolio.netlify.app می‌گیری. این آدرس را در مراحل بعد لازم داری.

  4. تنظیم فایل ادمین

    در گیت‌هاب فایل admin/config.yml را باز کن و با آیکون مداد ویرایشش کن. دو مقدار را عوض کن. مقدار اول، خط repo است:

    repo: YOUR_GITHUB_USERNAME/my-portfolio

    به‌جای YOUR_GITHUB_USERNAME نام کاربری گیت‌هاب خودت را بنویس. مقدار دوم، خط site_url است. آدرس نتلیفای خودت را در آن بنویس، با https:// در ابتدا. بعد Commit changes را بزن.

  5. ساخت اپ ورود در گیت‌هاب

    در گیت‌هاب این مسیر را برو: Settings، بعد Developer settings، بعد OAuth Apps، بعد New OAuth App. فیلد Application name هر نامی می‌تواند باشد. در Homepage URL آدرس سایت نتلیفای را بنویس. در Authorization callback URL دقیقاً این آدرس را بنویس:

    https://api.netlify.com/auth/done

    روی Register application بزن. بعد روی Generate a new client secret بزن. مقدار Client ID و Client Secret را کپی کن. رمز فقط یک بار نمایش داده می‌شود.

  6. اتصال اپ ورود به نتلیفای

    در نتلیفای سایتت را باز کن و برو به Site configuration، بعد Access & security و بخش OAuth. روی Install provider بزن و GitHub را انتخاب کن. مقدارهای Client ID و Client Secret را وارد و ذخیره کن.

  7. ورود به پنل ادمین

    آدرس سایتت را باز کن و در انتهایش /admin/ بگذار. مثلاً:

    https://my-portfolio.netlify.app/admin/

    روی Login with GitHub بزن و اجازه بده. بعد از ورود فرم‌های ویرایش را می‌بینی: متن‌ها، پروژه‌ها، لینک‌ها، رنگ‌ها، فونت و افکت‌ها.

  8. ویرایش و انتشار تغییرها

    داخل پنل مثلاً بخش پروژه‌ها را باز کن و عنوان و لینک را عوض کن. برای فایل رزومه و عکس، فیلد مربوط را بزن و فایل را بارگذاری کن. بالای صفحه روی Save بزن، بعد Publish و Publish now. بین چند ثانیه تا یک دقیقه بعد، نتلیفای سایت را خودکار به‌روز می‌کند. برای دامنه‌ی شخصی در نتلیفای بخش Domain management را باز کن.

اگر در مرحله‌ای خطا دیدی، متن خطا یا عکس صفحه را بفرست تا همان‌جا حلش کنیم.
